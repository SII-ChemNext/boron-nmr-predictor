# GNN Variant Model Comparison Experiment Results

**Task**: Boron NMR Chemical Shift Prediction
**Framework**: 5-Fold Cross-Validation + Hold-out Test Set Ensemble Evaluation

---

## Dataset and Split

| Item | Value |
|------|----|
| Raw Dataset | `../graph_transformer/data.csv` |
| Total Samples | 5490 |
| Dev Set (80%, used for 5-Fold CV) | 4392 |
| Test Set (20%, Hold-out) | 1098 |
| Random Seed | 42 |

The original 2D benchmarks use `processed_boron_dataset_v3.pt`. The three 3D
models use `processed_equivariant/train_3d.pt` and `test_3d.pt`, generated by
`build_equivariant_dataset.py` from the same rows and deterministic split.
All models use a learnable solvent embedding and the same 20 prior ML features,
but their graph encoders and prediction heads are architecture-specific.

### 2D benchmark configuration

| Parameter | Value |
|------|----|
| Models | GCN, GATv2, GINE, NNConv, PNA |
| Graph | 2D covalent graph + virtual node |
| Learning Rate | 0.0002779315932228636 |
| Hidden Dim | 256 |
| Dropout | 0.012558398103042557 |
| Early Stopping Patience | 10 |

### 3D equivariant benchmark configuration

| Parameter | Value |
|------|----|
| Models | fixed-coordinate EGNN, PaiNN, MACE |
| Conformer | one ETKDGv3 conformer; MMFF94 optimization, UFF fallback |
| Spatial Graph | directed radius graph, 5.0 Å cutoff; covalent edges always retained |
| Node / Edge Features | 58 / 11 |
| Radial Basis | 32 Gaussian functions |
| Batch Size / Learning Rate | 16 / 0.0003 |
| Solvent / ML Fusion Dim | 32 / 20 → 64 |
| Max Epochs / Early Stopping | 150 / 30 |
